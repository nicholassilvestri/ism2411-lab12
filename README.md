# ism2411-lab12
ISM2411 Lab 12 — Read a Sales CSV, Write a Cleaned Report

Name: Nicholas Silvestri

Description

This project reads sales data from a CSV file, calculates total revenue, filters orders over $100, and creates a cleaned CSV report. It also uses DictReader to summarize sales by product and appends each program run to a log file.

Files
csv_practice.py — Main Python program containing Exercises 1–8.
data/sales.csv — Original sales data.
data/cleaned.csv — Filtered sales report.
data/run_log.txt — Log of program executions and total revenue.
